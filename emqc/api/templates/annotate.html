改标签

P 拾取（任何工具下 Alt+点击）
F 填充连通区域 · Shift+点击改整片同 id
K 智能填充：按电镜的膜边界圈出细胞，橙色预览，Enter 填为当前标签
X 切割：画一条线穿过色块把它切开，较大的一块保留原色
D 分离：把点到的块从同色不相连的块中分出来
清除：把点到的色块清成背景，再重新上色；Shift+点击清整片同色
修补损坏切片：黑带或白页上，用上下相邻切片的细胞形状插值补回标签，先预览再应用
M 合并：先点 A 再点 B，B 变成 A 的颜色；每一对独立，只改当前片点到的色块
B 画笔 · E 橡皮 · [ ] 半径
N 新建 ID · Ctrl+Z 撤销

所有改动写到工作目录的 seg_edit.npy，交付目录里的 seg.npy 与 PNG 不会被碰。
