数据采集

从云端 precomputed 卷（Neuroglancer 生态）按 XYZ 取数据。顺序是：看卷 → 预判 ROI 值不值得 → 注册（不下载，按需读）或下载落盘。注册后它就是一个普通数据集，QC、Patch Factory、交付全部照常。

1 · 卷信息 不下载体素

2 · ROI 预判 几秒，先别爬

masking 是组织类型分割图，不是缺陷掩码。只有 fissure（裂隙）是成像缺陷，neuropil（神经毡）才是有突触可学的区域。换算时逐轴取倍数：masking 是 64/64/66 nm，ROI 是 8/8/33 nm，所以 x、y 除 8 而 z 只除 2，三轴统一会读到完全不同的位置且不会报错。

3 · 注册 / 下载

注册后不复制任何体素：QC 与 patch 生成按需读取，按 z-chunk 缓存（一次取回覆盖 32 张切片）。请求范围会向外吸附到 chunk 网格——同样的流量拿到更多数据，所以默认开启。下载落盘用于同一块数据要反复读的场景，任务可中断续传。
