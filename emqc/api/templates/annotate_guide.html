使用说明

工作台参照 Harvard VAST 的看图习惯：EM 做底图，分割按透明度盖在上面，滚轮翻 z，一手看图一手改标签。这一页把工具、快捷键和数据去向说清楚；工作台里按 ? 有精简版。

看图与对比

叠加
一个画面：EM 底图 + 分割上层，透明度滑块或 , . 调；勾「透明度渐变」（G）分割在 EM 上来回淡入淡出，适合看边界贴不贴。
并排
V 切换。左边纯 EM、右边 EM+分割，缩放、平移、翻页同步，光标联动；可勾「右侧仅分割」。
对比滑块
C。同一张图上拖一根黄线：线左是原图，线右是叠加。
闪烁
按住 Tab 临时隐藏分割，松开恢复。
边界
O 只画每个分段的轮廓，不填色。
3D
“看这一点”启用后点击图像；U 可直接查看光标处。“看整块”打开块范围。按钮高亮表示启用，再次点击或 Esc 取消并关闭查看器；切换工具、切片、数据块也会取消。
翻页
滚轮或 ↑ ↓；左栏「连播」按设定速度连续翻 z，用来顺着看一个细胞的走向。
缩放 / 平移
Ctrl+滚轮缩放，0 适合窗口，1 1:1；右键拖动或 H 平移。

改标签

拾取 P
点有颜色的区域，将其标签选为「当前标签」；点背景保留当前选择。标注工具下 Alt+点击也可拾取。
填充 F
点到的连通区域改成当前标签；Shift+点击改整片里所有同 id 的像素。按已有标签走，标签缺失或穿帮时会漫出去。
合并 M
两次点击：先点 A，再点 B，B 点到的那块变成 A 的颜色（id）。每一对独立，做完再点 C、D；只改当前切片点到的色块，不跨片。
清除
把点到的色块清成背景 0，之后可以用任何工具重新上色；Shift+点击清掉整片同色。清除不改变你的当前标签，所以"清掉再用同一个颜色重画"是两步连贯操作。
画笔 B / 橡皮 E
按半径涂当前标签 / 涂成背景 0；[ ] 改半径。
当前标签
填充、画笔和 SAM 应用使用的标签。翻片保留选择，因此它不一定已经出现在本片。初始未选择时请先拾取或新建标签。
新建标签 N
分配未使用的标签，避开本片已有颜色，立即选为当前标签。新建标签保存在工作目录的 created_labels.json；刷新后保留，可跨片复用。
撤销 Ctrl+Z
按次精确回退，每次改动都记录了每个像素的旧 id。
本片分段
分为“新建标签”和“已有标签”两组；新建标签涂色后仍留在新建组，尚未涂色的显示“未使用”。点一行选中，搜索框同时过滤两组。

数据去向

数据目录
只读。由 EMQC_ANNOTATE_ROOT 指定，EMQC_ANNOTATE_EXTRA_ROOTS 可用分号追加更多根目录；每个含 em.npy 的子目录是一个块。交付目录里不会多出一个字节。
工作目录
{{ workdir }}/<block>/：第一次改动时把 seg.npy 复制成 seg_edit.npy（写时复制），之后每次改动写一个 edits/<n>.npz，edits.jsonl 是摘要。修好的标签就是 seg_edit.npy，形状与 dtype 同原始。
细胞间隙
平台保留的通用标签（「细胞间隙」按钮选颜色；I 键更进一步：光标放在一块空白上按 I 直接把那一块填为间隙，封闭小洞一键填满，连成大网的会自动切到画笔让你扫），在每个数据块里都是同一个 id、同一个颜色（白色）。若本片有细胞的颜色接近白色，「当前标签」下方会出提示、标签列表里会标「近白」，以免混淆。分割里的 0 只表示「还没人标」，确认某块地方确实是细胞之间的空隙时，用它记下来。它只会落在 id 为 0 的像素上：画笔扫过细胞不会盖掉细胞，往细胞上点填充会被拒绝，也不能参与合并。空白在这种数据里常常连成一张贯穿全片的网（实测一片上 97% 的空白像素连成一块），所以对着一条缝点填充如果会涂掉一大片，会被拒绝并告诉你有多少像素：要涂那一段就用画笔扫过去（笔再大也只落在空白上），确实要把本片全部空白标成间隙就用整片填充（Shift+点击）。封闭的小洞照常一点一个。反过来不限制——先标成间隙、后来发现是某个细胞，照常用那个细胞的颜色盖上去。
显示方向
与源数据集一致：屏幕横轴是体数据的 X、纵轴是 Y，和 Neuroglancer 里的同一块画面完全重合，所以「看这一点」跳过去不会错位。磁盘上的数组是 (X, Y, z)，页面显示的是它的转置，原始 em.npy / seg.npy 没有改动，改的只是怎么画。因此交付目录的 visual/slices_em/ 与屏幕差一个转置，EM 底图一律现渲染。visual/slices_seg_color/ 是掺了 EM 灰度的彩色图，不能当标签，标签只来自 seg.npy。
颜色
页面上的颜色由 id 哈希生成，同一个 id 在任何片、任何块都是同一个颜色；合并后 B 变成 A 的颜色就是因为它拿到了 A 的 id。
SAM 预标注
没有分割的块可以先用 scripts/sam_label.py 在 GPU 上跑 Segment Anything，输出到 {{ sam_dir }}/<block>_sam/，自动出现在「数据块」列表，再来这里修。已有可信标签的块不要这样做：机器的划分会替掉人工结果，而且 id 是另一套编号，改完并不回去。页面左栏的 SAM 只作用于当前切片，默认仅填未标注。
预览与落笔
SAM 辅助分两步：先算出一个候选区域给你看（青色），确认后才写盘。点选和框选后自动显示预览，再次点击当前 SAM 工具或按 Esc 取消（不会撤销已保存的改动）。预览只存在服务端内存里，15 分钟过期；这期间如果标签被别的操作改了，应用会被拒绝并要求重新点选，不会覆盖更新的结果。

已知限制

  • 填充、涂抹、合并都是二维的，只改当前这一片；三维分裂（把错并的细胞拆开）还没做。
  • 没有多人并发控制：同一个块同时开两个页面改，后写的覆盖先写的。
  • 没有登录与权限；服务端 EMQC_ALLOW_DELETE_FILES=0 时任何页面都删不了磁盘文件。
