# SAM 分割质量评估：H01 人脑皮层 50 张切片

评估对象是 Segment Anything 在 `h01_b0000_demo_data` 左上象限（512²）z0–z49 上的自动分割输出，共 2626 个原始掩膜，
用交付的人工标签（2680 个细胞连通域）作为比较基准。五个角度独立测量，测量脚本和图在 `scratchpad/`。

## 一、结论

**能用，但只有一种用法能省钱：拿它去填人工还没标的大片空白，别拿它替换已有的人工标签。**

按每 512² 切片的标注工时估算，四条路线的排序是：

| 路线 | 工时/片 |
|---|---|
| 从合并块开始修（保留交付标签，只填空白） | **7.4 分钟** |
| 校对交付标签 + 手工补空白 | 10.3 分钟 |
| 让原始 SAM 取代交付标签 | 21.9 分钟 |
| 全部手工画 | 34.6 分钟 |

让 SAM 取代人工标签比什么都不做还贵一倍。单位成本是假设值（合并 2 次点击、切割一条线、手画一个中等细胞若干笔），
写在评估脚本里可以替换重算。

## 二、这份报告有多可信

必须先说清楚，因为它影响你怎么读下面的数字。

五个测量角度共提出 **48 条结论**，其中 37 条被标记为「会影响最终判断」，进入了对抗性复核环节：每条派三个独立的
反驳者，分别从「重算一遍」「有没有别的解释」「是不是在说真值而不是在说 SAM」三个方向攻它。

**因为用量上限，只有 3 条真正拿到了票，而且三条全部被驳回。** 剩下 34 条没有经过复核。

被驳回的三条都属于「边界精度」这一组，而且都是同一种情况：**三个反驳者各自独立重写脚本，算出一字不差的同样数字，
但认为解读站不住**。

| 原结论 | 反驳意见 |
|---|---|
| 85.2% 的边界落在 2 像素内，说明 SAM 轮廓精度好 | 这主要在测真值的分辨率和 IoU≥0.5 这道筛选门槛，不是在测 SAM |
| SAM 有一致的 0.76 像素外扩 | 数字对，但「一致」站不住，而且偏移该归给谁记错了对象 |
| 这个外扩不能靠内收 1 像素修掉 | 支撑它的两个数字来自脚本的边界约定 bug；结论碰巧仍成立，但理由完全不同，且说的是交付标签的标注口径 |

**所以：下面第四节「边界精度」整节请当作存疑。** 其余四个角度的数字没有被复核过，请按「单次测量」看待，
不要当作定论。好在几个最关键的结论有多个角度交叉印证，我在文中标出了。

## 三、核心发现

### 1. 决定成败的是物体的粗细，不是面积

这是整份评估最有用的一条，**两个角度独立得出**。

| 最大内接半径 | 中位 IoU |
|---|---|
| 5–7 px | **0.000** |
| 7–10 px | **0.000** |
| 10–15 px | 0.824 |
| ≥15 px | 0.901 |

10 像素（mip1 下 8 nm/px，约 160 纳米直径）是一道硬墙，不是渐变。控制住面积再看：同样是 1000–3000 像素的细胞，
细的那一半中位 IoU 是 0.000、漏检 61%，粗的那一半是 0.864、漏检 25%。

按形状看同样清楚：宽度小于 10 像素的细胞漏掉 95%，小于 12 像素漏 87%，小于 16 像素漏 76%，16 像素以上漏 36%。

**这解释了为什么 SAM 在这批数据上整体表现差**：H01 皮层的大部分结构是细长的轴突和树突突起，正好落在墙下面。

### 2. 失败模式是「根本没画」，不是「画错了」

漏检的 1457 个细胞里，**94% 被 SAM 掩膜覆盖不到 20%，中位覆盖是 0.00**；85% 被所有掩膜的并集覆盖不到 5%；
42.5% 与任何掩膜精确零重叠。只有 3–5% 属于「被一个大掩膜吞掉」的粒度问题。

这直接决定了修复动作的种类：**不是切割，是从零画**。

### 3. 漏检占修复总成本的 93.7%

| 错误类型 | 数量 | 占修复成本 |
|---|---|---|
| 漏检 | 1270 个细胞（每片 25.4 个） | **93.7%** |
| 欠分割（一个掩膜吞多个细胞） | 46/2626 掩膜 = 1.8% | 少 |
| 过分割 | 33/2680 细胞 = 1.2% | 少 |
| 细胞器误检 | 约 266 个 | 少（只需删除） |

**我此前告诉你的「欠分割是最贵的错误」在这批数据上不成立。** 欠分割和过分割都很轻，每片只需约 1.4 次切割和
3.8 次合并。真正压倒一切的是漏检。

### 4. 瓶颈在 SAM 自己的置信度过滤，不在采样密度

自动掩膜生成器铺了 **64×64 = 4096 个提示点，间距只有 8 像素**——连 3 像素宽的突起都会被反复打点。
但最终只有 **52.5 个掩膜**活下来，存活率 1.3%。

**这是最有可为的改进方向**：调低 `pred_iou_thresh` 和 `stability_score_thresh` 有希望直接把漏检降下来，
不用换模型。另一个佐证是 SAM 的自评分数与实际表现**负相关**（−0.30）——它提大块时最自信，而大块盖不住小细胞，
所以**不能用 SAM 自带的置信度来筛掩膜**。

### 5. 逐片差异大半是噪声，和图像缺陷无关

逐片平均 IoU 从 0.214（z5）到 0.571（z37），看着落差巨大。方差分解显示：**观测到的片间标准差 0.083 里，
真实差异只占 53%**；按物体厚度对齐后真实差异只剩 17%，1225 对切片里只有 4–9% 的置信区间不重叠。
**逐片排名不可当真。**

更重要的是，**这 50 片根本没有可测的数据缺陷**：没有黑切，没有空白区，对比度极差只在 233–243 之间波动（±2%）。
我原以为这批数据的蒙太奇拼接会解释坏片，这个预设不成立。

秩回归给出归因：

| 解释变量 | R² |
|---|---|
| SAM 自身当片的产出量（掩膜数、覆盖多少真值面积） | **0.53** |
| 图像缺陷 | 0.20 |
| 组织内容 | 0.03 |

曾被当作拼接缝的 x≈218 那条线，安慰剂检验证明是假阳性——它是一条持续存在的解剖学边界，不是拼接缝。

### 6. 未标注区不是「稀疏漏标」，这推翻了我之前的说法

我此前对你说过：交付标签是散布全区的稀疏精校子集，所以「SAM 圈了交付没标的东西」不能算错。**这个前提在这个块上
是错的。**

未标注区是**一整块连通区域**：单个连通块占了未标注像素的 97.5%（z0）、99.7%（z25）、99.2%（z49）。
交付覆盖率随行号有明显梯度，y<96 是 0.0%，y416–447 是 85.7%。这是一条**覆盖边界**，不是随机稀疏——
交付标签根本无法裁决那片区域里的对错。

同时要修正另一个数字：我说过「SAM 覆盖中 37.5% 落在未标注区」，**实际是 56.5%**，那个数复现不出来。

### 7. SAM 独有的发现基本是真的，但多数是残片

857 个几乎完全落在未标注区的掩膜，用「轮廓是否压在暗膜上」这个与真值无关的判据衡量：

| | 贴膜程度（减去同形状随机对照） |
|---|---|
| 被交付验证过的掩膜 | +0.167 |
| SAM 独有掩膜 | **+0.268** |

**独有掩膜贴膜程度不低于、数值上还略高于被验证过的那些。** 80.8% 优于随机，92.9% 达到验证组的第 10 百分位门槛。
那片未标注区是货真价实的脑组织，不是树脂或空洞。

真正的缺陷是别的：**60.1% 的独有掩膜有至少两成轮廓压在 512 图幅边上**（交付验证组只有 29.8%），也就是被画幅切断的
半个断面。另有约四分之一是在均匀胞质里凭空切出来的块，轮廓不比随机好。

做这一节的测量者报告说，**他第一版的测量给出了完全相反的结论，原因是被亮度和对比度梯度骗了**，修正后才是上面的数。
这类错误在本项目里已经反复出现，值得记下来。

### 8. 跨片一致性坏到 3D 追踪不成立

2626 个实例连成 719 条链，**52.6% 只活 1 片**，平均 3.27 片。

要把一个平均跨 23.6 片的交付细胞在 SAM 结果里拼成单一的 3D id，平均需要处理 2.7 条链加 12.7 个无匹配的片，
合计 15.5 块、**14.5 次拼接**——而其中 12.7 片是压根没有匹配、得先手画出来的。整块算下来是 1.7 小时。

正确的解法不是调连接参数，是改推理方式：SAM 2.1 自带视频模式，把 z 当时间轴做掩膜传播，天生跨帧一致。
服务器上装的就是 2.1，代码里现在只用了图像模式。

### 9. SAM 的输出不是一份分割

21.8% 的被覆盖像素同时属于两个以上掩膜，18.2% 的掩膜整体嵌套在另一个里面（子块中位占父块 17%）。
这就是为什么原始掩膜必须先消歧才能当标签用，也是 `scripts/merge_sam_masks.py` 存在的原因。

顺带修正：我此前报的「过分割 6.5% 的细胞」**高估了约 5 倍**。其中 141/174 实际是「一个好掩膜 + 一个嵌套小块」，
修复动作是删除而不是合并，真实过分割是 1.2%。

## 四、边界精度（整节存疑，见第二节）

这一组的三条主要结论都被反驳者驳回了解读，但算术被三方独立复现。数字列在这里供参考，**不要据此下判断**。

| 指标 | 值 |
|---|---|
| 边界像素落在对方轮廓 ≤1px / ≤2px / ≤5px | 68.3% / 85.2% / 93.8% |
| 完全重合 | 27.8% |
| 逐细胞 p95 的中位 | 2.24 px = 17.9 nm |
| 面积比 SAM/交付 | 1.098 |
| 召回 / 精度（中位） | 0.991 / 0.895 |

一条可能有价值的观察：**IoU 会掩盖大细胞的拓扑失败**。面积超过 3000 像素且 IoU≥0.9 的细胞里，仍有 27.5% 存在
超过 10 像素的轮廓错误；面积超过 10000 像素的细胞 82.6% 如此。最差的形态是 SAM 把细胞的细长突起整段丢掉，
而 IoU 仍然判定为「匹配」。端到端算，2680 个交付细胞里只有 21.5% 是「匹配上且轮廓干净」。

这条与第 1、2 节的结论方向一致（细的丢掉），可以互相印证，但它本身没有经过复核。

## 五、对本项目的建议

**继续用现有的合并块方案。** `scripts/merge_sam_masks.py` 的设计——不覆盖交付标签、只填未标注区、丢掉压在已有
标签上和太小的掩膜——被评估证实是唯一省钱的用法。它把 SAM 输出的 73% 扔掉了，扔掉的恰好是会帮倒忙的那部分。

但要知道它没做完：**合并块里仍空白的 39.1%，一大半是真正的开阔区域而不是膜**，后面还有不少手工活。

**值得做的两件事，按性价比排：**

1. **调 SAM 的过滤阈值**。4096 个提示点只活下 52.5 个掩膜，降低 `pred_iou_thresh` 和 `stability_score_thresh`
   有希望直接改善漏检，成本是几分钟一次的重跑。
2. **改用 SAM 2 的视频传播**解决跨片一致性。收益比调连接参数大一个数量级。

**不值得做的：** 靠后处理修边界（内收 1 像素之类），实测增益是噪声级；以及指望 SAM 处理细长突起——
160 纳米那道墙是模型本身的性质。

## 六、诚实的局限

- **34 条结论没有经过对抗性复核**，仅 3 条被复核且解读全部被驳回。
- 交付标签是人工校对的子集，本身不是物理真值。「SAM 漏了交付标的细胞」是可靠的失败指标；
  「SAM 圈了交付没标的东西」在那片连通的未标注区里**无法裁决**。
- 所有测量都是片内二维的，33 纳米的层间距没有进入任何数字。
- 边界精度只在 SAM「匹配上」的那 45.6% 细胞上测，天然偏乐观。
- 只测了一个 512² 象限的 50 片。另外三个象限和其他数据集没有测过，尤其是标签覆盖率高得多的右下象限
  （78.6% 对这里的 32.9%），结论不一定可迁移。
