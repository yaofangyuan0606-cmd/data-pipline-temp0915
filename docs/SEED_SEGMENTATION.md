# 种子分割：大片灰区的单片补标

在 `/annotate` 左侧「种子分割」中按「选范围 → 标目标 → 确认填色」操作。当前步骤会高亮；无需 GPU，每次只处理当前切片和所选范围。SAM 默认收起在「SAM · 备用分割」中，需要时展开。

1. 点击「框选范围」，拖框包住一个目标和周围少量组织。框边尽量放在目标外。拖框靠近图像边缘时会自动吸附到最外侧；目标贯穿图像上下/左右边缘时，可直接点「全片范围」，包含所有边缘像素。
2. 自动切到「目标」。在目标内部点一下或画短线，松开鼠标后自动显示绿色半透明候选。绿色种子不要画在膜、已有颜色或细胞器内部；一个候选中的绿色种子代表同一个实例。
3. 若候选漏过膜进入邻居，点击「排除」在邻居内部画红点/短线，也可以按住 Shift 临时画红色种子。目标有漏选部分时补绿色种子。每次补种子都重新预览。
4. 「撤回一笔」只去掉最后一笔提示，不改变已保存标签。「重新开始」开始新的目标；再次点击当前工具或 Esc 取消。
5. 确认边界后点击「填为新标签」，或先拾取/选择已有 ID 后「填为当前标签」。可按住 Alt 在图上拾取已有颜色，或点击标签列表选择 ID，这两种方式保留预览；直接切到普通拾取工具会取消预览。鼠标停在「填为当前标签」上可查看目标 ID。
6. 应用仅补标签 0，已有标签保持原值。结果记为「种子分割」，Ctrl/⌘+Z 可撤销。翻片、换块会清除提示和预览；同事修改了本片时，旧预览不能应用。

展开「调整边界」可调整「边界尺度」（默认 1.2 px），或手动「重新预览」。小值保留细膜，大值平滑噪声；调整后重新计算。框选面积最多 1024×1024，最短边至少 8 px；种子离框边至少 2 px。每笔种子以约 3 px 宽绘制，最多 64 笔、总计 8192 个采样点。

候选接近框边时会提示检查范围；这不是准确率估计。种子分割不合适时，可展开「SAM · 备用分割」尝试另一种候选；切换到 SAM 会清除种子预览，收起 SAM 会取消未应用的 SAM 预览。不要以灰色减少多少判断质量，要同时看原图中的膜、细胞器和相邻切片。同一神经突起跨片应复用同一 ID，但当前版本不自动传播，也不会猜测跨片身份。

## 算法和限制

采用局部暗度与 Hessian 暗线响应构成膜强度图，再调用 scikit-image 的带标记分水岭。计算时读取框外最多 32 px 的图像上下文，将自动背景标记放到上下文外缘、框外的位置；框线本身不强制留白，图像边缘位于框内时也不强制留白。已有标签和排除种子仍作为背景标记；绿色种子作为目标标记，只保留连到绿色种子的候选连通域，最终严格裁回框内。整图框选且没有已有标签或背景参照时，需要添加红色排除种子。

这是借鉴 ilastik Carving 交互的 CPU 基线实现，不是 ilastik 训练好的分类器，也不是电镜专用神经网络。暗色细胞器、条带、膜缺口可能导致误分，需要补种子、改变范围或使用画笔/SAM 校正。没有整块自动填满、3D 传播或批量 Multicut。

## 接口与保护

- `POST /api/v1/annotate/blocks/{b}/seed/predict`：`{z, box:[x0,y0,x1,y1], strokes:[{label:1或0, points:[[x,y],…]}], scale:1.2, annotator?}`；box 右/下界不包含。返回 ROI PNG、box、token、像素数、耗时与提示。所有坐标与现有显示方向一致。
- `POST /api/v1/annotate/blocks/{b}/seed/apply`：`{token,new_id,annotator?}`。ID 通过字符串保留 uint64 精度，拒绝 0/负数/超出 dtype 的值。登录时操作者以服务端账号为准。

预览只存内存，15 分钟过期，最多保留 32 份。token 绑定源目录、工作目录、操作者和切片 revision。应用在原有 block 锁下再次检查版本、已有标签保护和 ID，再调用现有逐像素记录/撤销接口。预览不会新建 seg_edit.npy，日志来源属于「算法辅助」。

## 验证

`tests/test_seeds.py` 使用非正方形合成体数据验证沿膜分割、连续排除线、坐标方向、uint64、只补 0、来源记录、精确撤销、过期/跨用户/跨目录及同片修改后拒绝。

`tests/test_seeds_browser.py` 通过 `EMQC_PLAYWRIGHT_TESTS=1` 开启，在隔离数据上运行真实 CPU 接口，验证框选、种子、应用、撤销、翻片及迟到响应。测试的 TMPDIR、浏览器缓存与 basetemp 均需设在项目内。
