# SAM 切片补标使用指南

适用对象：在网页上查看电镜图像、修正分割和补充标签的同事。无需运行 Python。

SAM 2.1 根据你点的位置或画的框生成分割候选。**先核对青色预览，再应用为标签**；点击提示点本身不会改动标注。
当前功能逐张处理二维切片，不会自动修改相邻层，也不会一次补完整个数据块。

## 1. 打开页面，找到待补区域

打开部署者提供的网页，进入左侧 **切片标注**（地址以 `/annotate` 结尾）。选择数据块和层号，找到要补的区域。
如果刚更新过服务而没看到 **SAM 辅助分割**，刷新页面。

| 画面内容 | 含义 |
| --- | --- |
| 灰度 EM 和黑色线条 | 原始电镜图像；黑线常用于判断膜边界，但并非每条黑线都是目标外边界 |
| 已有彩色覆盖 | 现有实例标签；同一个标签 ID 在不同切片使用相同颜色 |
| SAM 青色覆盖 | 待应用的候选区域，还没有写入标签 |

看到灰度图不一定表示漏标：先确认右侧“分割（上层）”已勾选、透明度不是 0，且没有临时隐藏图层。
本功能把**标签 ID 为 0**的像素视为“未标注区域”；0 也可能包含膜或胞外空间，不需要把所有灰色都填满。

## 2. 第一次补标：圈出一个区域，再填为新标签

1. 保持左栏 **仅补未标注区域（标签 0）** 勾选。这样本次应用不会覆盖已有非零标签。
2. 点击 **SAM 点选**，在目标膜围成的区域**内部**点一下，尽量避开黑线、交界和不属于目标的细胞器。
3. 等待青色预览。首次使用要加载模型，后续在同一张图上补点通常更快；推理期间等按钮恢复后再操作。
4. 放大检查边界，尤其是细长突起、相邻细胞接触处和图像边缘。需要时按下一节修正。
5. 确认后点击 **填为新标签**。青色预览清除，区域显示为新标签的颜色，历史增加一条“SAM 分割”。
6. 再检查一次结果。填错时点击 **撤销**，或在图像区域使用 `Ctrl+Z`；Mac 也可用 `Command+Z`。

“填为新标签”会自动分配一个 ID，不必先点击普通工具里的“新建 ID”。如果一个候选包含多块不相连的区域，应用后它们也会获得同一个 ID；不同对象应分开选、分开应用。

## 3. 边界不准时怎么修正

普通点击或框选会清除旧提示，开始新目标。按住 **⌘（Mac）/Ctrl（Windows、Linux）** 点击才会累计正点，Shift+点击为当前目标添加排除点。绿点表示包含，红点表示排除。

| 情况 | 操作 |
| --- | --- |
| 漏掉目标的一部分 | 按住 ⌘/Ctrl，在漏掉的目标内部点击补点 |
| 把旁边的区域也圈进来了 | 按住 **Shift**，点击不应该包含的部分，添加排除点 |
| 点一下圈出整大片或只圈出内部细胞器 | 点击 **SAM 框选**，拖出紧贴目标外接范围的矩形，再切回点选，用 ⌘/Ctrl 补点、Shift 排除 |
| 结果有多种合理边界 | 在 **分割候选** 中比较“自动选择”和“候选 1/2/3”；候选编号不代表大小或质量排名 |
| 提示越加越乱，或点错了 | 点击 **清除提示**，重新框选或点选；当前没有单独撤销一个提示点的按钮 |
| 不想使用这次结果 | 点击“清除提示”或按 `Esc`，不应用即可 |

按住 ⌘/Ctrl 可以组合框选与点选；新的框替换旧框，补点最多 64 个。普通点击或不按快捷键框选会开始新目标。切换候选会重新计算预览。
“自动选择”按模型评分选候选，**评分不等于电镜标注准确率**。不同候选中哪个沿膜更合理，需要看图判断。

SAM 是通用模型，未针对本项目电镜微调；它可能跨过薄膜、把内部细胞器当目标，或把一块分成几块。
多次提示仍不合适时，清除预览，改用普通画笔/橡皮修正。当前没有在 SAM 预览上直接用画笔修改掩码的功能。

## 4. 补到已有对象，或修正已有颜色

### 给已有对象补一块缺失区域

1. 在 SAM 点选模式下，按住 **Alt** 点击已有彩色区域（Mac 为 Option），将它的 ID 选为“当前标签”。
2. 用正负点或框选圈出它缺失的部分，检查青色预览。
3. 点击 **填为当前标签**，把候选区域赋予所选 ID。默认仍只填标签 0。

Alt 拾色可以保留 SAM 提示。直接切换到普通“拾取”工具会清除预览，因此建议在 SAM 模式内用 Alt 拾色。
若当前标签为背景 0，先拾取一个非零标签，或使用“填为新标签”。

### 修正已经有颜色的区域

取消 **仅补未标注区域（标签 0）**，重新检查预测，再应用。
此时，候选内已有标签可能被替换；候选外的标签不变。应用后可撤销。
仅修改这次候选覆盖的像素，不会自动删除原标签在其他位置或其他切片的剩余部分。

如果两个已有色块应该合为一块，通常可直接使用普通 **合并** 工具：先点保留颜色的块，再点要改色的块。

## 5. 检查结果、保存与撤销

| 操作 | 用途 |
| --- | --- |
| Ctrl + 滚轮 | 放大/缩小图像 |
| 右键拖动 | 平移图像 |
| 按住 Tab | 临时隐藏已有分割和 SAM 预览，查看原图；松开恢复 |
| 右侧透明度滑块 | 调整已有标签叠加透明度；不控制青色 SAM 预览 |
| 并排视图（V） | 并排比较 EM 和已有分割；SAM 预览会显示在两边 |
| 滚轮、上下箭头、层号控件 | 切换切片；未应用的 SAM 提示和预览会清除 |
| 撤销 / Ctrl+Z / Command+Z | 撤销最近一次已保存的标注操作，不是撤销一个提示点 |

**应用即保存，无需再点“保存”。** 改动写入服务器配置的工作目录：

```text
EMQC_ANNOTATE_WORKDIR/
  <block_id>/
    seg_edit.npy      当前标签副本
    edits/            逐次撤销记录
    edits.jsonl       编辑历史摘要
```

原始 `em.npy`、`seg.npy` 不会被 SAM 应用覆盖。刷新页面会重新读取已保存的工作副本。
交付当前结果时，请让维护者从对应工作目录取 `seg_edit.npy`，而不是从旧的彩色 PNG 预览取结果。
保留编辑历史文件，才能继续使用精确撤销。当前没有重做按钮。

同事共用服务器时，请分配不同数据块，避免同时修改同一块。当前没有多人编辑锁；撤销作用于该块最近一次编辑，并不按用户区分。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 模型显示未安装、加载失败或 CUDA 不可用 | 联系部署者，按 [SAM 部署与接口说明](SAM.md) 检查安装和 GPU |
| 没有青色预览 | 先选 SAM 工具并在图像上点选/框选，等待预测；查看左栏结果提示 |
| 提示“没有可填区域” | 默认模式已扣除已有标签；确认目标有标签 0，或在需要覆盖时取消“仅补未标注区域” |
| “填为新标签/当前标签”不可用 | 需要有非空预览，且该数据块有 `seg.npy` 标签基线；推理期间按钮暂时禁用 |
| “预览已过期”或“标注已变化” | 点击“预览分割”重新预测后再应用。预览最多保留 15 分钟，也会因服务重启或缓存淘汰失效 |
| 翻片后预览没了 | 正常行为。当前提示只属于当前切片，应先应用再翻片 |
| 选了新标签，别的切片没有跟着改 | 正常行为。当前只做二维补标，没有跨片自动传播或自动建立对象对应关系 |
| 升级后图像和标签方向不一致 | 停止编辑并联系维护者。当前数组约定为 `(行, 列, z)`，不要自行对已有工作副本再次转置 |

部署、配置和 API 见 [SAM.md](SAM.md)；普通标注工具的完整说明见 [ANNOTATE.md](ANNOTATE.md)。
