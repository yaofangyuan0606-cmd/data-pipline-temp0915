# 数据集科普：mouse_30um 与连续切片电镜数据

> 面向第一次接触 EM 数据的工程师。先讲这块数据物理上是什么、怎么变成硬盘上的 png，再讲图里能看到什么、缺陷从哪来、QC 的结论对训练意味着什么。带 ⚠ 的是尚未与数据提供方确认的推测。

## 1. 这份数据是什么

`project_terminal/<用户>/datasets/datasets/mouse_30um`，584 MB，4650 个 png。名字的意思大概率是"小鼠（mouse）脑组织、边长约 30 µm 的立方块" ⚠。

| 目录 | 内容 | 格式 | 说明 |
|---|---|---|---|
| `em/mip1` | 100 张 2048×2048 EM 原图 | 8 位灰度 png | QC 用的就是这一层，最高可用分辩率；**没有 mip0** |
| `em/mip2` – `mip4` | 同样 100 张，边长依次 1024 / 512 / 256 | 8 位灰度 | mip2 是 mip1 的 2×2 均值（实测相关 0.99） |
| `seg/mip1` – `mip4` | 100 张分割标签 | RGB png | 每个像素是一个"神经元 ID"，ID 拆成 R/G/B 三个字节存 ⚠；`seg/mip0` 是空目录 |
| `delete/axon`, `cellbody`, `dendrites`, `synapse`, `vesicle` | 各 750 张 4096×4096 类别掩码 | 调色板 png，值为小整数 | 标注覆盖 750 张，比 EM 的 100 张多；文件夹名 `delete` 的含义待确认 ⚠ |
| `delete/synapse+vesicle` | 100 张 4096×4096 | 同上 | 只有 100 张，很可能与 EM 的 100 张对应 ⚠ |

**尺寸推算 ⚠**：类别掩码是 4096 像素、按 mip0 算，30 µm ÷ 4096 ≈ 7.3 nm/px；mip1 就是 ≈ 14.6 nm/px，一张 2048² 切片覆盖约 30 µm × 30 µm；750 张切片对应 30 µm 厚度 → 每张约 40 nm。这个数需要数据提供方确认，QC 里的物理阈值（错位多少 nm 算严重）依赖它。

按平台的 block 定义（1024²×100），这份数据被切成 4 个 block，每个 block 约覆盖 15 µm × 15 µm × 4 µm ⚠ 的组织。

## 2. 一块脑组织是怎么变成 100 张图片的

连续切片电镜（ssEM，serial-section electron microscopy）的流水线，每一步都会留下特定的"指纹"，也就是 QC 要抓的缺陷：

1. **固定与染色**：用锇、铀、铅等重金属给组织染色。重金属吸附在细胞膜、蛋白密集处，电子打上去散射多，成像为**暗**。所以 EM 图里黑线是膜，灰是胞质，亮是空隙。这也是为什么 EM 图天然是灰度图，没有颜色。
2. **树脂包埋**：把组织块灌进树脂固化，变成一块可以切的"塑料"。
3. **超薄切片**：金刚石刀把树脂块切成 30 到 50 nm 厚的薄片，比可见光波长还薄。切片时组织可能被**压缩**（section deformation）、**起皱或撕裂**（fold / crack），个别切片会**丢失**（missing）或切坏。
4. **收集与成像**：切片收到载带或硅片上，扫描电镜（SEM）逐张成像。一张切片太大，一次只能拍一个视野，所以一张切片是由许多 **tile** 拼起来的。电子束照射会让绝缘部位积累电荷，形成亮条纹或光晕（**charging**）；灰尘落上去就是**污染**（contamination）；束流和探测器随时间漂移带来**亮度与对比度变化**。
5. **拼接与对齐**：tile 拼成整张（stitching），再把上下相邻切片对齐（alignment）。拼接不好就有**接缝和棋盘状明暗**（mouse_30um 里很明显），对齐不好就是**错位**：整张平移是全局错位，局部对不上是局部错位，非刚性拉扯是局部形变。切片顺序搞错就是 **z-order 错误**。
6. **导出**：对齐后的三维体按切片导出成图片。没有数据的地方（裂缝、缺 tile、对齐后移出画面的边角）用 **0 填充**，这就是我们看到的黑色斜带和黑角。

## 3. 图里能看到什么

在 mip1（约 15 nm/px ⚠）的尺度上：

- **细胞膜**：细黑线，把画面分成一个个封闭区域，每个区域是一个神经元或胶质细胞的截面。分割模型主要就是学这些线。
- **胞体与细胞核**：大而圆的区域，核内有颗粒状染色质，核膜是双层黑线。拼图里 z0 到 z63 那个逐渐移动的大圆就是一个胞体。
- **轴突与树突**：细长的管状截面；树突上有棘（spine）。
- **线粒体**：胞质里的椒圆形深灰结构，内部有条纹（嵴）。
- **突触**：两个细胞紧贴处的一段增厚黑色膜（突触后致密区）加一侧成堆的小圆泡（囱泡，vesicle）。`delete/synapse` 与 `delete/vesicle` 掩码标的就是这些。
- **髓鞘**：包着某些轴突的多层厚黑环。
- **血管与胶质**：偶尔出现的大空腔和形状不规则的细胞。

## 4. mip 金字塔与体素

- **mip**（多分辩率金字塔的层级）：mip0 是原始分辩率，每升一级在 x、y 各缩小一半（2×2 平均），像素数变为四分之一。mip1 到 mip4 的边长 2048 → 1024 → 512 → 256 正是这个关系。看整体结构用高 mip，看突触细节要低 mip。
- **体素各向异性**：xy 方向的像素尺寸（约 15 nm ⚠）远小于 z 方向的切片厚度（约 40 nm ⚠），一个体素是扁的柱体。所以相邻两张切片之间的差异比相邻两个像素之间大得多，这也是序列 QC 要把比较尺度统一到 32 nm/px 的原因：在这个尺度上相邻切片才有稳定的相关性。
- **为什么 seg 有 mip0 而 em 没有**：分割标签是从更高分辩率的原图上做的，导出时把 EM 的最高层省掉了（体积大），或者根本没有一起拷过来 ⚠。
- **训练常用层级**：分割一般在 mip1 或 mip2 训练（约 8 到 16 nm/px），太细浪费算力，太粗丢膜。你定义的 1024²×100 block 与公开基准 SNEMI3D 的体积尺寸相同 ⚠（凭公开资料，未本地核对）。

## 5. 分割标签与类别掩码

- **seg（segmentation）**：每个像素一个整数 ID，同一 ID 的所有像素属于同一个神经元。这里用 RGB png 存，读的时候要把三个通道拼回一个整数（例如 `id = R + 256·G + 65536·B`）⚠，不能当彩色图理解。0 通常是背景或未标注。
- **GT（ground truth）**：经人工校对的分割，是训练和评测的"标准答案"。`seg/` 在注册表里登记为 `gt_segmentation`。
- **类别掩码**：`delete/` 下按 axon、cellbody、dendrites、synapse、vesicle 分的图，像素值是小整数编号：axon 与 dendrites 整栈用到 0 到 10，vesicle 用到 0 到 50（单看第 0 张只出现其中几个值，例如 axon 的 2、5、8、10）。它们可能是子类别编号，也可能是某个标注工具的导出约定 ⚠。平台把它们登记为 `gt_annotation` 并记下类别名。
- **训练目标**：分割网络通常预测膜概率或亲和度（相邻像素是否同属一个细胞），再用分水岭和聚合得到实例；突触检测、细胞器分割是另外的任务，用对应掩码训练。

## 6. 缺陷、成因与我们怎么检

| 你会看到什么 | 通常的成因 | 平台里的检查 | 在 mouse_30um 里 |
|---|---|---|---|
| 整张灰色平板 | 切片丢失、成像失败后用常数占位 | `blank_slice` | z8 全是 128 |
| 文件根本不存在 / 打不开 | 传输遗漏、写盘中断 | `missing_slice` / `corrupt_slice` | 无 |
| 黑色斜带横贯切片 | 切片起皱或撕裂，导出时无数据填 0 | `crack` | 15 张切片为 critical，另 2 张细裂缝为 high / medium；整张切片零值占比 8% 到 38%，落在单个 tile 内最高 94% |
| 边角黑块 / 未成像区域 | 对齐后移出视野、缺 tile；边界呈直线加规则台阶（台阶高度约 16 px，即采集 tile 网格） | `crack` 检查报为 `no_coverage`（贴边的大块）或 `missing_region`（内部小块） | mouse_30um 的 z2、z4、z7、z9 等 12 张 |
| 一张明显发糊 | 对焦漂移、切片厚度异常 | `severe_blur` | 只有轻微波动（low） |
| 大片纯黑或纯白 | 探测器饱和、曝光错误 | `saturation` | 扣掉填充区后很少 |
| 相邻两张亮度跳一级 | 束流 / 探测器增益变化、tile 拼接明暗 | `brightness_jump` | 63 条 low、14 条 medium、3 条 high（z39、z49、z79 在左上 tile 因此不通过）、1 条 critical（z86 裂缝切片）；分布与棋盘状明暗一致 |
| 对比度慢慢变化 | 染色不均、束流漂移 | `contrast_drift` | 未触发 |
| 亮条纹、光晕 | charging | `charging_artifact`（未实现） | 未查 |
| 深色团块 | 灰尘、沉淀 | `contamination`（未实现） | 未查 |
| 上一张和下一张对不上 | 切片丢失、内容突变 | `slice_jump` | z8 及裂缝切片 |
| 整张平移 | 对齐失败 | `global_misalignment` | 未触发 |
| 部分区域对不上 | 拼接 / 局部对齐失败 | `local_misalignment` | 未触发 |
| 顺序颠倒、重复 | 收集或命名错误 | `z_order_error` | 未触发 |
| 拉伸、压缩、非刚性扭曲 | 切片受力变形 | `local_deformation` / `section_deformation`（未实现） | 未查 |
| 棋盘状明暗 | tile 之间亮度未校正 | 尚无专门检查，建议 v0.2 加 `tile_seam` | 非常明显 |

## 7. QC 结论怎么读

- **留存率 87%，4 个 block 全是 B 级**：每 100 张里有 11 到 15 张不能直接用，主要是裂缝。B 级的含义是"剔除坏切片后可用"，不是"数据有问题不能用"。
- **最长连续可用段 14 到 28 张**：训练 3D 模型时一个 patch 在 z 方向最多取这么多张。在 40 nm 切片厚度下 ⚠，28 张约 1.1 µm 厚。
- **裂缝的 bbox**：每条裂缝都有全分辩率坐标，可以在切 patch 时避开，也可以反过来专门采样带裂缝的区域训练鲁棒性。
- **tile 拼接明暗**：大多只到 low / medium，但在左上 tile 让 z39、z49、z79 三张因亮度突变达到 high 而不通过；它还会让模型学到假的亮度边界。建议训练前做 tile 级归一化，或在 v0.2 加专门检查后按严重程度处理。

## 9. 术语小表

| 术语 | 一句话 |
|---|---|
| ssEM | 连续切片扫描电镜：切一片拍一片再摞回去 |
| section / slice | 一张物理切片 = 一张图片 = 一个 z |
| voxel | 三维像素；这里 xy 约 15 nm、z 约 40 nm ⚠ |
| mip | 分辩率层级，每级边长减半 |
| tile | 一张切片由多个视野拼成，每个视野是一个 tile |
| stitching / alignment | tile 拼接 / 相邻切片对齐 |
| block | 平台的 QC 与采样单元：1024² 像素 × 100 张 |
| segmentation / seg | 每个像素属于哪个细胞的标签图 |
| GT | 人工校对过的正确答案 |
| affinity | 相邻像素是否同属一个细胞的预测，分割模型的常见输出 |
| synapse / vesicle | 突触 / 囱泡，连接组学最关心的结构 |
| crack / fold | 切片撕裂 / 起皱，导出后是零值带 |
| charging | 电子束电荷积累造成的亮条纹光晕 |
| retention rate | 留存率：QC 通过的切片占比 |
| grade | block 等级 A/B/C/D：直接可用 / 剔坏片后可用 / 仅短连续段 / 不可用 |

## 10. 需要向数据提供方确认的事

1. 体素尺寸：xy 与 z 各多少 nm。
2. `delete/` 文件夹的含义和掩码里小整数值的编码。
3. EM 的 100 张对应 750 张标注中的哪 100 张。
4. seg 的 RGB 编码方式（ID 是否为 R + 256G + 65536B）。
5. 是否有 mip0 的 EM 原图，以及 tile 拼接明暗是否已知、是否有校正版本。
